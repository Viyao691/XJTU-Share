## 计划初衷与简介

准备一门课的考试，往往要先找课件、找往年题、找答案，再把分散的资料拼起来。我希望把自己收集和使用的课程资料整理成一个能直接浏览、按年份查找、持续补充的共享仓库，让后来的同学少花一些搜集资料的时间。

这个仓库最初是为我正在开发的「考试大王」整理原始资料而建立的。课件、试题、例题和笔记是构建课程知识库与向量检索索引的基础；保留原件、来源关系和年份依据，才能在加工知识点和解答时回到原始材料核对。现在将这些原始资料公开，希望既服务项目，也方便同学们独立下载、学习和补充。

这里是个人整理的课程资料分享项目。资料来自不同年份与不同来源，课程要求、教学进度和答案可能存在差异；使用时请结合自己的授课内容判断。

## 考试大王

**网站：[https://viyao.cn](https://viyao.cn)**

「考试大王」是面向大学课程复习与考试准备的学习工具，围绕课程资料、知识点、典型例题和历年试题组织复习内容，并通过知识库与检索索引帮助查找和理解相关知识。它希望把资料整理、知识检索和复习安排连接起来，让复习更有条理。

本仓库保存原始资料，考试大王项目另行维护加工后的知识库、向量索引和应用功能。**资料公开不等于对应课程知识库已上线**；理论力学、数字电子技术的知识库仍处于搭建阶段，暂不上线。

## 文件目录规范

按“学科全称 → 资料类型”组织；同一学科的试卷再按年份分目录。以下为目录结构示意，分类以各学科实际资料为准：

```text
学科全称/
├── 课件/
├── 试卷/
│   ├── 2023年/
│   ├── 2024年/
│   ├── 跨年合集/
│   └── 年份待核/
├── 习题与例题/
├── 教材与参考书/
├── 笔记与复习/
└── 归档说明/
```

- **单年目录**：按现有卷面校勘记录或文件名、原目录的年份标签归档；具体依据见清单。学年、出版年份不直接当作考试年份。
- **跨年合集**：一份文件含多个年份的试卷，整份保留，不强行归入某一年。
- **年份待核**：没有可靠年份、标签冲突或尚未确认卷面日期的资料，集中保留，避免猜测。
- **原始文件**：保留文件内容和来源关系；原目录中的同名文件通过下级目录区分。

[materials-manifest.csv](materials-manifest.csv) 和 [materials-manifest.json](materials-manifest.json) 记录源相对路径、归档路径、文件 SHA-256、资料身份、年份依据与疑点；`actual_year` 只填写已有校勘或验收记录确认的考试年份。

自动控制理论的历史文件名关系见 [电子重构新旧文件名对照](自动控制理论/归档说明/电子重构新旧文件名对照.json)。部分理论力学 PDF 原本加密且没有密码，保留原件并在清单中标记为未读取。

## 如何使用与下载

### 浏览或下载单个文件

从课程导航进入相应目录，打开文件后使用 GitHub 的下载入口。若页面显示 Git LFS 指针，请选择原始文件下载，不要把几行指针文本当成 PDF 或课件。

### 下载完整仓库

大文件使用 **Git LFS** 保存。安装 Git 和 Git LFS 后运行：

```sh
git lfs install
git clone https://github.com/Viyao691/XJTU-Share-2026.git
cd XJTU-Share-2026
git lfs pull
```

完整原始资料约 1.52 GiB，请预留下载空间。使用 GitHub 的 ZIP 下载时，内容是否包含 LFS 原件取决于仓库归档设置；用 Git LFS 克隆是获取完整资料的推荐方式。

### 考试大王项目的子模块

本仓库仍作为考试大王主仓库的 `materials` 子模块使用：

```sh
git lfs install
git submodule update --init materials
git -C materials lfs pull
```

资料共享与课程知识库加工分别维护；下载原始资料无需运行考试大王项目。

## 贡献与反馈

**欢迎贡献大家的新资料。** 课程资料、缺失年份的试卷、答案校勘及有用的学习笔记，都欢迎补充。

1. 将资料放入对应学科与类型目录；试卷按卷面年份归档，不能确认的放入 `年份待核`。
2. 尽量直接上传 PDF、Word、PowerPoint 等可浏览的原始文件，不把整门课打成压缩包；大文件使用 Git LFS。
3. 在 Pull Request 中说明来源、适用课程、年份及资料身份，区分原卷、回忆、重构、参考答案和个人解答。
4. 上传前确认具有分享权限，去除不适合公开的姓名、学号、联系方式等个人信息；不要提交账号、密码或密钥。

没有条件直接提交资料，也可以通过 [Issues](https://github.com/Viyao691/XJTU-Share-2026/issues) 提供补充线索。发现分类错误、年份冲突、答案问题或文件损坏时，请附上路径和具体位置，方便核对。

### 第六条 学生有下列情形之一，学校可以给予开除学籍处分：

- （五）学位论文、公开发表的研究成果存在抄袭、篡改、伪造等学术不端行为，情节严重的，或者代写论文、买卖论文的；

### 第十四条 学生应当自觉维护学校的教学秩序，遵守学校的教学管理规定。扰乱教育教学秩序者，视其情节轻重给予下列处分：

- （五）在公开发表的学术论文、报告、设计中或在提交的学位论文、课程设计、毕业设计中，存在抄袭、篡改、伪造等学术不端行为，情节较轻且认识态度端正者，给予留校察看处分，情节严重者，给予开除学籍处分; 购买、出售或者组织买卖、由他人代写、替他人代写或组织代写学术论文、学位论文、课程设计、毕业设计者，给予开除学籍处分；
