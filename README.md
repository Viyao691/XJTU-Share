# 考试大王原始资料私有归档

本仓库只保存17门学科的原始资料逐字节副本、归档说明和清单；不包含知识库、向量、加工缓存或用户数据。试卷按单年标签、跨年合集及年份待核分目录。数字年份目录可以仅来自文件名或源目录，具体依据见清单；actual_year 仅填写已有校勘或验收记录确认的考试年。学年及出版版本年份不等同卷面考试年。理论力学、数字电子技术和电力系统分析的归档不表示课程已上线。

`materials-manifest.json` / `.csv` 记录源相对路径、归档路径、SHA-256、身份、年份依据和疑点。自动控制理论的电子重构历史文件名另见 `自动控制理论/归档说明/电子重构新旧文件名对照.json`；原源页对照 JSON 按原字节保存。

主仓库以子模块引用本仓库，克隆后运行：

```sh
git lfs install
git submodule update --init materials
git -C materials lfs pull
```

资料仅供私有归档，不随课程 Web/API 发布。
